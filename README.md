## About the new version

The new version still uses **libmpv** as its playback core. Anime4K real-time
super-resolution, subtitles, and danmaku are retained and improved. Network
storage (WebDAV / SMB / FTP), casting, and download management have been added.

The new version uses a **different package name**, so it is a **separate app**.
It can coexist with the legacy version, but settings and playback history are
**not** migrated automatically.

For features, installation instructions, and the latest release, see the new
repository's README and Releases.
